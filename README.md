# Student Assessment Management and Progress Tracking System

A web-based mini-project developed for the Professional Development assessment.

## Project purpose

The system is intended to support the management of students, assessments, results, feedback and academic progress in one application.

## Planned technology stack

HTML, CSS and JavaScript for the front end, PHP for server-side functionality, and MySQL for persistent data storage.

## Project management

Development is managed using an Agile/Scrum workflow in Jira. Jira work item identifiers are referenced in development commits where appropriate.

## Current development stage

### SCRUM-14 – Produce system wireframes

The initial low-fidelity application wireframes are stored in `docs/wireframes/`.

The wireframes cover:

Dashboard, Students, Add Student, Edit Student, Assessments, Create/Edit Assessment, Student Results, Record Result, and Progress Overview.

The file `generate_wireframes.py` contains the Python source code used to generate the wireframe images.
